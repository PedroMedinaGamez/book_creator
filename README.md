# book_creator

Repositorio para la creación de libros mediante skills de Claude.

## Estructura

```
book_creator/
├── README.md
├── .gitignore
└── skills/        # Aquí van las skills (una carpeta por skill, con su SKILL.md)
```

## Skills

Cada skill vive en su propia carpeta dentro de `skills/`:

```
skills/
└── nombre-de-la-skill/
    └── SKILL.md
```
